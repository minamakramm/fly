# AI Assistant Rules and Project Conventions\n\nToolchain\n- Editor: VS Code\n- Terminal AI: Gemini CLI or GitHub Copilot / any free AI coding assistant\n- Runtime: Node.js LTS\n- Version control: Git + GitHub\n\nProject rules\n- Forms use explicit validation functions that return a field->error object; never inline validation inside the submit handler.\n- Keep DOM access in a single init function and keep business logic pure for testing.\n- Validate select inputs against an exact allowlist, not just truthiness.\n\nProject conventions\n- Use Conventional Commits: feat:, fix:, chore:, docs:, style:, refactor:, test:\n- Keep commits small and focused\n- Prioritize readable filenames and simple API contracts\n\nREADME critique workflow\n- Ask the AI assistant to review the README for clarity and completeness.\n- Apply at least one AI-suggested improvement.\n\nStack preferences\n- Prefer React or Next.js for frontend work\n- Use Tailwind CSS or CSS Modules for styling\n- Keep project logic modular and testable\n
